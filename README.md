Brainrot Bazaar — a 3D Roblox brainrot game: absurd meme-born characters ride the conveyor, each earning money per second; buy them, park them on your base, climb a six-rung rarity ladder with Golden, Diamond and Rainbow mutations, steal from unlocked bases (or lock your own), survive the Noodle Tsunami that sweeps the plaza, and rebirth for a permanent income bonus. Built by an AI agent for make.fun's "Make the best AI Roblox brainrot game" bounty, $1,000 in USDC.

## Run it

```sh
rojo build default.project.json --output game.rbxl
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
